# 海洋探險家 ocean.hunglun.com

以國立海洋生物博物館（海生館）的展館與特展為主題，認識臺灣海域約兩百種海洋生物的教學互動網站。幼兒園到高中四種程度，不用註冊、不用安裝。

## 工具
海洋小百科（含比一比）、逛海生館、特展教室（讀一篇答五題）、分類闖關、誰住哪片海、猜猜我是誰（幼兒園：聽名字找照片）、翻牌配對、保育小尖兵、海洋探究（eDNA 測站地圖、鯨豚海龜擱淺紀錄）、探險護照、老師專區（學習單、出題投影、搶答計分板、課程包）。

## 資料來源（政府資料開放授權條款第1版）
- 魚類介紹：文化部典藏目錄－國立臺灣博物館魚類典藏（data.gov.tw 8716）
- 海洋保育類名錄、eDNA 調查、鯨豚與海龜擱淺：海洋委員會海洋保育署（161739、172487、157624、157957）
- 展館與特展：國立海洋生物博物館（9693、90320）
- 學名對照：臺灣物種名錄 TaiCOL
- 鯨豚與海龜介紹改寫自中文維基百科（CC BY-SA 4.0）；照片為維基共享資源自由授權照片，作者與授權見各物種介紹頁
- 地圖輪廓：Natural Earth（公有領域）；字型：Noto Sans TC（SIL OFL 1.1）

國小與幼兒園的白話介紹、特展測驗由本站依原文改寫，只用原文寫到的事實，並以 `tools/ai_check.py`、`tools/unit_check.py` 檢查。

本站非國立海洋生物博物館製作。鴻綸科技 製作；不蒐集任何個人資料，學習紀錄只存在使用者自己的瀏覽器。

## 開發
- 靜態網頁在 `public/`，資料 `public/data/*.json` 由 `tools/` 的 Python 腳本產生
- 一支 Cloudflare Worker：送靜態檔，每月 1 日檢查資料集有沒有更新（ntfy 通知）
- `npm test` 資料完整性檢查；push main 由 GitHub Actions 部署
